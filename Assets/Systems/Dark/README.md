# Dark-theme system logos

These 11 dark-theme variants are derived from the corresponding PNG logos in the parent directory. Only the picker uses these variants, and only in the dark theme. The original files remain the light-theme artwork. When no variant exists for the active theme, the picker uses the original artwork.

All variants preserve original dimensions and alpha channels exactly, including antialiasing. Neutral RGB tones (maximum channel spread of 12) are inverted to brighten dark lettering while retaining colored details. CorsixTH retains its original icon in the left third of the image and inverts only neutral tones in the text region. BBC Micro uses reflected HSL lightness, retaining its blue-violet hue while making its dark silhouette bright.
